# 测距与网格记录模块

## 模块概述

测距与网格记录模块为水下考古人员提供了在沉船平面图上进行精确测量的工具。通过比例尺校准、坐标网格和多点测距功能，考古人员可以在平面图上快速测量文物间距、船体尺寸等关键数据，并将测量结果与潜次、文物标记关联管理。

## 功能清单

### 1. 比例尺校准
- **功能**：通过已知实际长度的参考物建立像素与实际距离的换算关系
- **操作**：在地图上点击两点 → 输入实际距离 → 完成校准
- **应用**：所有网格和测距功能均依赖校准后的比例尺

### 2. 坐标网格
- **功能**：在地图上叠加可配置的坐标网格
- **配置项**：
  - 网格大小（单位：米，支持 0.1 米及以上）
  - 坐标标签显示开关
  - 网格显示/隐藏切换
- **视觉**：
  - 主线：每 5 条网格线加粗显示
  - 次线：常规线宽
  - 标签：显示实际距离标注

### 3. 测距功能
- **功能**：在地图上点击多个点创建折线测距
- **特点**：
  - 支持 2 个及以上点（折线测量）
  - 实时显示累计距离
  - 点编号显示（P1, P2, ...）
  - 距离标注显示

### 4. 测距记录管理
- **字段**：
  - 编号（如 MEAS-001）
  - 所属潜次
  - 长度（自动计算，单位：米）
  - 备注
  - 关联标记（可多选文物标记）
- **操作**：
  - 创建新测距
  - 编辑已有测距
  - 删除测距记录
  - 在地图上高亮选中记录

### 5. 数据持久化
- **本地存储**：所有数据自动保存到浏览器 localStorage
- **导出**：导出为 JSON 文件（v3.0 格式），包含所有潜次、标记、测距、比例尺和网格配置
- **导入**：支持导入 v3.0 格式数据，可预览冲突并选择解决策略

## 使用指南

### 快速开始

1. **校准比例尺**
   - 点击「校准比例尺」按钮
   - 在地图上点击起点和终点
   - 在弹窗中输入实际距离（米）
   - 点击「确认校准」完成

2. **显示网格**
   - 点击「显示网格」按钮切换网格显示
   - 在侧栏「测距与网格」标签页中调整网格大小
   - 可开关坐标标签显示

3. **创建测距**
   - 点击「开始测距」按钮
   - 在地图上依次点击测量点（至少 2 个）
   - 在侧栏填写编号、选择潜次、添加备注
   - 勾选关联的文物标记
   - 点击「保存测距」完成

### 操作说明

#### 比例尺校准
- 校准前请确保参考物在平面图上清晰可辨
- 建议使用已知尺寸的物体作为参考（如船体构件、标尺等）
- 校准后所有测量功能自动使用新比例尺

#### 网格使用
- 网格原点位于地图左上角
- 网格大小会根据比例尺自动计算像素间距
- 窗口大小变化时网格自动重绘

#### 测距操作
- 点击「取消测距」可放弃当前测量
- 保存后测距线变为绿色实线
- 点击列表中的记录可在地图上高亮显示
- 删除记录前会确认提示

## 数据结构

### 比例尺数据 (Scale)

```javascript
{
  pixelDistance: 245.5,     // 两点间像素距离
  realDistance: 2.5,        // 实际距离（米）
  unit: "米",               // 单位
  createdAt: "2025-06-20T10:30:00.000Z"  // 校准时间
}
```

### 网格配置 (GridConfig)

```javascript
{
  enabled: true,            // 是否启用网格
  size: 1,                  // 网格大小（米）
  showLabels: true,         // 是否显示坐标标签
  originX: 0,               // 原点 X 坐标（百分比）
  originY: 0                // 原点 Y 坐标（百分比）
}
```

### 测距记录 (Measurement)

```javascript
{
  id: "uuid-string",        // 唯一标识
  code: "MEAS-001",         // 编号
  dive: "DIVE-01",          // 所属潜次编号
  points: [                 // 测量点数组（至少 2 个）
    { x: 42.5, y: 46.2 },
    { x: 58.3, y: 39.1 },
    { x: 65.7, y: 52.8 }
  ],
  length: 3.45,             // 总长度（米）
  note: "船艏到第一根船肋的距离",  // 备注
  relatedMarks: [           // 关联标记 ID 数组
    "mark-uuid-1",
    "mark-uuid-2"
  ],
  createdAt: "2025-06-20T10:35:00.000Z"  // 创建时间
}
```

### 导出文件格式 (v3.0)

```json
{
  "version": "3.0",
  "exportDate": "2025-06-20T10:40:00.000Z",
  "dives": [ ... ],
  "marks": [ ... ],
  "measurements": [ ... ],
  "scale": { ... },
  "gridConfig": { ... }
}
```

## 技术实现

### 架构设计

模块采用分层架构：

```
┌─────────────────────────────────────┐
│              UI 层                   │
│  (地图交互、表单、列表、渲染)         │
└───────────────┬─────────────────────┘
                │
┌───────────────▼─────────────────────┐
│             App 层                   │
│  (业务逻辑、状态管理、CRUD 操作)      │
└───────────────┬─────────────────────┘
                │
┌───────────────▼─────────────────────┐
│          DataIO 层                   │
│  (本地存储、导入导出、文件操作)       │
└───────────────┬─────────────────────┘
                │
┌───────────────▼─────────────────────┐
│        Validation 层                 │
│  (数据校验、对比、冲突解决)           │
└─────────────────────────────────────┘
```

### SVG 渲染系统

#### 坐标系统
- 使用 `viewBox="0 0 100 100"` 建立百分比坐标系
- `preserveAspectRatio="none"` 确保 SVG 填满容器
- 所有坐标使用 0-100 的数值，对应百分比位置

#### 图层设计
- **grid-layer**：网格图层，位于底层
- **measure-layer**：测距图层，位于上层
- 两个图层均设置 `pointer-events: none`，不影响地图交互

#### 关键样式
- `vector-effect: non-scaling-stroke`：确保描边宽度不随 SVG 缩放变化
- `paint-order: stroke`：文字先描边后填充，提升可读性

### 性能优化

1. **防抖重绘**：窗口 resize 时使用 150ms 防抖，避免频繁重绘
2. **按需渲染**：仅在状态变化时重新渲染相关图层
3. **innerHTML 批量更新**：使用 innerHTML 一次性更新 SVG 内容，减少 DOM 操作

## 扩展开发

### 添加新的测量工具

1. 在 `index.html` 中添加工具栏按钮
2. 在 `ui.js` 中添加对应的交互逻辑和渲染函数
3. 在 `app.js` 中添加数据处理逻辑
4. 在 `dataIO.js` 中添加存储方法
5. 在 `validation.js` 中添加校验函数

### 自定义坐标系统

如果需要修改坐标原点或坐标轴方向：

1. 修改 `renderGrid()` 函数中的坐标计算
2. 修改标签显示逻辑
3. 更新文档说明

### 支持多段折线测量

当前已支持多段折线测量（多点）。如需显示每段的长度：

1. 在 `renderMeasure()` 和 `renderMeasurements()` 中遍历每段
2. 在每段中点添加分段长度标签
3. 可选择性地在列表中显示分段详情

## 常见问题

### Q: 为什么校准后网格线没有变化？
A: 请确保网格显示已开启（点击「显示网格」按钮）。网格大小会根据比例尺重新计算像素间距。

### Q: 测距点可以撤销吗？
A: 当前版本暂不支持单步撤销。如需重新测量，点击「取消测距」后重新开始。

### Q: 可以同时显示多条测距线吗？
A: 可以。所有已保存的测距记录都会显示在地图上，编辑中的记录会高亮显示。

### Q: 导入旧版本数据会丢失测距信息吗？
A: 不会。导入 v2.0 格式数据时，测距相关字段为空，原有标记和潜次数据正常导入。

### Q: 比例尺校准后可以修改吗？
A: 可以。随时可以重新校准，新的比例尺会立即应用到网格和所有测距显示。
